# Code of Conduct

## Our Commitment

Neram is committed to providing a welcoming, respectful, and harassment-free
environment for everyone who participates in the project.

We welcome contributions from people of all backgrounds and experience levels.

## Expected Behavior

Participants are expected to:

- Be respectful, constructive, and considerate
- Assume good intentions
- Focus on technical issues rather than people
- Give and receive feedback professionally
- Respect different opinions and approaches
- Help maintain an inclusive project community

## Unacceptable Behavior

Harassment, discrimination, personal attacks, trolling, threats, intimidation,
unwanted sexualized language or advances, publishing private information without
permission, and deliberate disruption are not acceptable.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of
Conduct. They may take any action they consider appropriate, including warnings,
removal of contributions, or temporary or permanent exclusion from project
participation.

## Scope

This Code of Conduct applies to GitHub issues, pull requests, discussions,
project-related communications, and other spaces where someone is representing
Neram.

## Reporting

Report unacceptable behavior privately to the project maintainer. Do not
publish sensitive personal information in a public issue.

## Attribution

This Code of Conduct is inspired by the Contributor Covenant.
